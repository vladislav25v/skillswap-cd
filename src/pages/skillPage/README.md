# SkillPage

Страница навыка — детальная информация о навыке и пользователях.

## Используемые компоненты

- `Header` — шапка сайта (из `widgets/Header`)
- `Footer` — подвал сайта (из `widgets/Footer`)
- `SkillDetailsPanel` — карточка навыка с галереей (из `widgets/SkillDetailsPanel`)
- `UsersListSection` — секция с пользователями (из `widgets/UsersListSection`)
- `SectionBlock` — обёртка для секций (из `widgets/SectionBlock`)
- `Avatar` — аватар пользователя (из `shared/ui/Avatar`)
- `SkillsTags` — компонент для отображения навыков с цветовой категоризацией (из `shared/ui/Skilltags`)


## Моковые данные

Для отображения используются временные моковые данные:
- Навык: Фотография (описание, категория, галерея)
- Пользователи: 4 пользователя с аватарами, навыками, городами

## Особенности

- Используются реальные компоненты из `shared/ui` и `widgets`
- Цвета тегов определяются через `SkillsTags` на основе категорий из макета
- Адаптивная вёрстка: 4 карточки в ряд (десктоп) → 3 → 2 → 1 (мобильные)

## Известные проблемы

- Цвета тегов пока могут не соответствовать макету, так как компонент `SkillsTags` ожидает данные от API (порт 3001). После запуска мок-сервера проблема решится.
- Тень в `SkillDetailsPanel` убрана через переопределение стилей, так как не соответствует макету.

## Пропсы

Компонент не принимает пропсы (статический).
