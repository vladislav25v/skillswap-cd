# SkillPage

Страница навыка (детальная страница с информацией о навыке и пользователях).

## Используемые компоненты

- `Header` — шапка сайта (из `widgets/Header`)
- `Footer` — подвал сайта (из `widgets/Footer`)
- `Details` — блок с детальной информацией о навыке (в разработке, временно заглушка)
- `SectionBlock` — блок с карточками пользователей (в разработке, временно заглушка)


## Особенности реализации

- Использованы временные заглушки для компонентов `Details` и `SectionBlock`, которые находятся в разработке
- Стили соответствуют макету и используют глобальные CSS-переменные

## Пропсы

Компонент не принимает пропсы.

## Пример использования

```tsx
import { SkillPage } from './pages/skillPage';

function App() {
  return <SkillPage />;
}
