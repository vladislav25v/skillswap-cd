# CatalogPage

`CatalogPage` — страница каталога пользователей.

## Что рендерит
- `Header`
- `FilterSidebar`
- `SectionBlock`
- `UsersListSection`
- `UserCard`

## Источник данных
Страница получает данные через API-слой:
- `getUsers`
- `getSkills`
- `getSubcategories`
- `getCities`

Для локальной разработки используется моковый сервер на базе `public/db/db.json`.

## Логика страницы
- по умолчанию отображаются секции:
  - `Популярное`
  - `Новое`
  - `Рекомендуем`
- кнопка `Смотреть все` у секции `Популярное` открывает общий список с сортировкой по популярности
- кнопка `Смотреть все` у секции `Новое` открывает общий список с сортировкой по дате регистрации
- при активных фильтрах также показывается общий список `Входящие предложения`
- кнопка сортировки в общем списке переключает порядок:
  - `Сначала новые`
  - `Сначала популярные`

## Особенности
- страница читает состояние фильтров из Redux
- данные пользователя преобразуются в props карточки через `mapUserToCardProps`
- возраст пользователя вычисляется через `getUserAge`
