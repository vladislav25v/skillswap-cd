# ErrorPage404

Страница ошибки 404 (Страница не найдена).

## Используемые компоненты

- `Header` — шапка сайта (из `widgets/Header`)
- `Footer` — подвал сайта (из `widgets/Footer`)
- `Button` — кнопки (из `shared/ui/Button`)

## Ресурсы

- `404-icon.svg` — векторное изображение для страницы (лежит в `src/assets/`)

## Особенности реализации

- Фон страницы — `--color-page-bg` (`#F9FAF7`)
- Отступ сверху от Header: `100px`, снизу до Footer: `84px`
- Логотип в Footer расположен аналогично Header (отступы `36px` от края)
- Кнопка "На главную" использует `window.location.href = '/'` (без перезагрузки роутинга, чтобы не менять `main.tsx`)

## Пропсы

Компонент не принимает пропсы.

## Пример использования

```tsx
import { ErrorPage404 } from './pages/error404';

function App() {
  return <ErrorPage404 />;
}

## Стилизация

Все стили находятся в ErrorPage404.module.css и используют CSS-модули.
Цвета и типографика берутся из глобальных CSS-переменных.
