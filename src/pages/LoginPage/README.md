# LoginPage

Страница входа в SkillSwap.

## Что включает

- Логотип (`Logo`) в верхней части страницы
- Заголовок `Вход`
- Левая колонка с формой авторизации:
  - кнопки-заглушки `Продолжить с Google` и `Продолжить с Apple`
  - разделитель `или`
  - поля `Email` и `Пароль`
  - кнопка показа/скрытия пароля
  - кнопка `Войти`
  - ссылка-кнопка `Зарегистрироваться`
- Правая колонка с иллюстрацией и приветственным текстом

## Используемые компоненты

- `shared/ui/Button/Button`
- `shared/ui/Input`
- `shared/ui/FormField`
- `shared/ui/Logo`
- `shared/ui/Title`

## Используемые ассеты

- `src/assets/Google.svg`
- `src/assets/Apple.svg`
- `src/assets/light-bulb.svg`

## Состояния и поведение

- `email` — значение поля email
- `password` — значение поля пароля
- `isPasswordVisible` — переключение типа поля пароля (`password`/`text`)
- `isAuthError` — состояние ошибки авторизации

Логика сабмита в текущей реализации демонстрационная:
- валидные значения: `demo@skillswap.ru` и `skillswap`
- при неверных данных показывается сообщение об ошибке под блоком полей
- кнопки Google/Apple являются заглушками (`type="button"`)

## Особенности верстки

- Две фиксированные колонки `556 x 692` с `padding: 60px`
- Промежуток между колонками: `24px`
- Контент колонок центрируется по высоте
- Все цвета, шрифты и размеры опираются на глобальные CSS-переменные из `src/index.css`
- Для вертикальных отступов в форме используется подход `flex + gap`

## Пример использования

```tsx
import LoginPage from '@/pages/LoginPage/LoginPage';

function App() {
  return <LoginPage />;
}
```
