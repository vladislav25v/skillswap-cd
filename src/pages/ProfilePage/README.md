# ProfilePage

Лейаут для страниц профиля с боковой навигацией и областью контента.

Компонент используется вместе с `react-router-dom` и предназначен для построения вложенных маршрутов через `Outlet`.

---

## Props

| Prop        | Type     | Default | Description                             |
|-------------|----------|---------|-----------------------------------------|
| `className` | `string` | —       | Дополнительный CSS класс для контейнера |

---

## Структура

Компонент формирует двухколоночный layout:

```html
<main class="main">
  <aside class="sidebar">
    <!-- AsideNav -->
  </aside>

  <div class="content">
    <!-- Outlet -->
  </div>
</main>
```

--- 

## Состав

| Часть      | Description                          |
|------------|--------------------------------------|
| `AsideNav` | Боковая навигация профиля            |
| `Outlet`   | Контент текущего вложенного маршрута |
