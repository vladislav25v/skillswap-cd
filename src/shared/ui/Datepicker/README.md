# Datepicker

Компонент выбора даты, построенный на базе `react-datepicker` и интегрированный с UI-компонентами проекта (`Input`,
`Button`).

Компонент предоставляет:

- поле ввода даты с иконкой календаря
- выпадающий календарь
- выбор месяца и года через dropdown
- кнопки **Отменить** и **Выбрать**
- локализацию на русский язык
- управление значением через `value` и `onChange`

В отличие от стандартного `react-datepicker`, выбор даты применяется **только после нажатия кнопки "Выбрать"**.

---

## Props

| Prop       | Type                           | Default | Description                            |
|------------|--------------------------------|---------|----------------------------------------|
| `value`    | `Date \| null`                 | —       | Текущая выбранная дата                 |
| `onChange` | `(date: Date \| null) => void` | —       | Callback при подтверждении выбора даты |

---

## Поведение

Компонент использует **временное состояние** (`tempDate`):

1. При открытии календаря `tempDate` копирует `value`
2. Пользователь выбирает дату
3. Изменение сохраняется во временное состояние
4. После нажатия **Выбрать** вызывается `onChange`
5. После нажатия **Отменить** значение сбрасывается

Это позволяет избежать мгновенного применения выбранной даты.

---

## Примеры

### Базовое использование

```tsx
import { useState } from 'react';
import Datepicker from '@/shared/ui/Datepicker';

const [date, setDate] = useState<Date | null>(null);

<FormField label="Дата рождения">
  <Datepicker value={date} onChange={setDate} />
</FormField>
```

---

## Локализация

Календарь использует локаль русского языка через `date-fns`.

```ts
registerLocale('ru', ru)
```

---

## Ограничения выбора

Дата ограничена текущим днём:

```ts
maxDate = { new Date() }
```

Нельзя выбрать дату из будущего.


--- 

## UI особенности

Компонент включает:

- кастомный `Input`
- иконку календаря (`CalendarDays`)
- dropdown выбора месяца
- dropdown выбора года
- кнопки действий

| Кнопка       | Действие                    |
|--------------|-----------------------------|
| **Отменить** | Сбрасывает дату             |
| **Выбрать**  | Подтверждает выбранную дату |

---

## Popper модификатор

Используется кастомный modifier floating-ui, который корректирует позицию календаря:

```ts
state.x = 0
state.y += 4
```

Это добавляет небольшой отступ между input и календарём.
