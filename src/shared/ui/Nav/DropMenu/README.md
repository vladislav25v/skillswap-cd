# DropMenu

`DropMenu` рендерит выпадающее меню навыков, которое использует `Nav`.

## Пропсы

- `isOpen`: управляет открытием и закрытием
- `sections`: готовые секции меню
- `onClose`: закрывает меню
- `triggerRef`: ссылка на кнопку-триггер
- `isLoading`: показывает состояние загрузки
- `error`: показывает ошибку загрузки

## Поведение

- открывается и закрывается с анимацией
- закрывается по клику вне меню
- закрывается по `Escape`
- удерживает фокус внутри, пока открыто
