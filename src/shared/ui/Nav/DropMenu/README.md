# DropMenu

`DropMenu` — выпадающее меню навыков для компонента `Nav`.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `isOpen` | `boolean` | - | Управляет монтированием и видимостью меню |
| `sections` | `MenuSection[]` | - | Готовые секции меню: категория в `title`, подкатегории в `items` |
| `onClose` | `() => void` | - | Колбэк закрытия меню |
| `triggerRef` | `RefObject<HTMLButtonElement \| null>` | `undefined` | Ссылка на кнопку-триггер, чтобы клик по ней не считался кликом вне меню |
| `isLoading` | `boolean` | `false` | Показывает состояние загрузки данных |
| `error` | `string \| null` | `null` | Показывает текст ошибки загрузки |

## Поведение

- Меню открывается и закрывается из `Nav`
- Закрывается по клику вне меню
- Закрывается по нажатию `Esc`
- Пункты меню сейчас работают как заглушки: по клику ничего не происходит

## Данные

Сейчас `DropMenu` получает готовые данные через props. Источник данных для `Nav` — временный файл `api.ts` в этой же папке, который читает `categories` и `subcategories` из `json-server`.

В будущем этот слой можно заменить на `RTK` или `RTK Query`, не меняя сам UI-компонент.
