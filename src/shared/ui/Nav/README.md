# Компонент Nav
Компонент Nav — это навигационная панель, реализованная на React с использованием функциональных компонентов и CSS Modules. Он содержит основные ссылки и выпадающее меню, которое раскрывается при клике.
## Nav.tsx
Меню содержит две основные ссылки:
- "О проекте" — ведет к секции #about
- "Все навыки" — с иконкой стрелки, при клике открывает/закрывает выпадающее меню.
- Стейт isDropdownOpen управляет видимостью выпадающего меню.
- ul className={styles.dropdownMenu} пока используется как заглушка, на его месте будет компонент DropMenu.

## Nav.module.css
- Верстка навигационной панели (.navbar)
- Стиль элементов меню
- Оформление выпадающего меню (.dropdownMenu)
- Позиционирование и отступы.
