# Nav

`Nav` — компонент навигации с кнопкой `Все навыки`, которая открывает `DropMenu`.

## Состав

- ссылка `О проекте`
- кнопка `Все навыки`
- компонент `DropMenu`

## Поведение

- по нажатию на кнопку `Все навыки` меню открывается и закрывается
- состояние открытия хранится в `isDropdownOpen`
- данные для меню загружаются при монтировании `Nav`
- при загрузке меню получает `isLoading`
- при ошибке загрузки меню получает `error`

## Данные

`Nav` запрашивает:

- `categories`
- `subcategories`

Данные читаются через временный файл api.ts, после чего в `Nav.tsx` преобразуются в массив `sections` для `DropMenu`.

Структура одной секции:

```ts
type MenuSection = {
  id: number;
  title: string;
  items: {
    id: number;
    name: string;
  }[];
};
```

## Связь с DropMenu

`Nav` передаёт в `DropMenu`:

- `isOpen`
- `sections`
- `onClose`
- `triggerRef`
- `isLoading`
- `error`

`triggerRef` нужен, чтобы клик по кнопке `Все навыки` не считался кликом вне меню.
