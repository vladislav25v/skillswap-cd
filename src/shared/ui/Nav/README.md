# Nav

`Nav` рендерит верхнюю навигацию и управляет выпадающим меню навыков.

## Состав

- ссылка `О проекте`
- кнопка `Все навыки`
- компонент `DropMenu`

`Nav` не принимает внешние пропсы.

## Поведение

- загружает категории и подкатегории при монтировании
- преобразует данные API в `MenuSection[]`
- открывает и закрывает `DropMenu` через локальное состояние
- передает в меню состояния загрузки и ошибки
