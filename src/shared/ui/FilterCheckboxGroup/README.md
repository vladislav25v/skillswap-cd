# FilterCheckboxGroup

Универсальный компонент для отображения группы чекбоксов в фильтрах с поддержкой вложенных категорий и интерактивных состояний.

## Особенности

- Поддержка вложенных категорий (subOptions)
- Индикаторы открытия/закрытия категорий
- Состояния чекбоксов (checked, indeterminate, disabled)
- Анимация стрелок при открытии/закрытии
- Адаптивный перенос текста
- Доступность (aria-атрибуты, фокус-состояния)
- Поддержка ссылки "Все категории" с SVG иконкой
- Hover и focus эффекты с использованием цветовой схемы

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | - | Заголовок группы фильтров |
| `options` | `FilterOption[]` | - | Массив опций для отображения |
| `name` | `string` | - | Название группы (для идентификации) |
| `className` | `string` | `''` | Дополнительный CSS класс |
| `showAllLink` | `boolean` | `false` | Показывать ли ссылку "Все категории" |
| `allLinkText` | `React.ReactNode` | `'Все категории'` | Текст/контент ссылки "Все категории" |
| `onAllLinkClick` | `() => void` | - | Обработчик клика по ссылке |
| `onChange` | `(selectedValues: string[]) => void` | - | Обработчик изменения выбранных опций |

### FilterOption

Интерфейс опции фильтра:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | - | Уникальное значение опции |
| `label` | `string` | - | Текст метки |
| `category` | `'business' \| 'art' \| 'languages' \| 'education' \| 'home' \| 'health' \| 'more'` | - | Категория для стилизации |
| `subOptions` | `FilterOption[]` | - | Вложенные подкатегории |
| `defaultChecked` | `boolean` | `false` | Выбрана ли опция по умолчанию |
| `disabled` | `boolean` | `false` | Отключена ли опция |
