# Title

Компонент заголовка для отображения `h1–h4` с управлением **семантическим тегом** и **визуальным стилем**.

Позволяет разделить:

- **семантику** (`tag`) — какой HTML тег будет использован
- **визуальный стиль** (`looksLike`) — как заголовок будет выглядеть

Это полезно для **SEO**, **accessibility** и построения правильной иерархии заголовков на странице.

---

## Props

| Prop        | Type                           | Default | Description                                                     |
|-------------|--------------------------------|---------|-----------------------------------------------------------------|
| `tag`       | `'h1' \| 'h2' \| 'h3' \| 'h4'` | `'h1'`  | HTML тег заголовка                                              |
| `looksLike` | `'h1' \| 'h2' \| 'h3' \| 'h4'` | —       | Визуальный стиль заголовка. Если не задан, наследуется от `tag` |
| `text`      | `string`                       | —       | Текст заголовка                                                 |
| `children`  | `React.ReactNode`              | —       | Контент заголовка (имеет приоритет над `text`)                  |
| `className` | `string`                       | —       | Дополнительный CSS класс                                        |

---

## Особенности

- поддерживает теги `h1`, `h2`, `h3`, `h4`
- можно разделять **семантику и визуальный стиль**
- если передан `children`, он **имеет приоритет** над `text`
- `className` добавляется к базовым стилям компонента

---

## Примеры

### Базовый заголовок

```tsx
import Title from 'shared/ui/Title';

<Title text="Главная страница" />
```

### Использование children

```tsx
<Title tag="h2">
  Список пользователей
</Title>
```

### Разделение семантики и внешнего вида

```tsx
<Title tag="h2" looksLike="h1">
  Большой заголовок внутри секции
</Title>
```
