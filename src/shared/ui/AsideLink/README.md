# AsideLink

Компонент для создания навигационных ссылок в сайдбаре с поддержкой:

- активного состояния
- отображения иконки рядом с текстом
- поддержки всех свойств компонента `NavLink` из `react-router-dom`

Компонент автоматически добавляет класс для активной ссылки и отображает иконку (если передана).

---

## Props

| Prop             | Type                          | Default | Description                                    |
|------------------|-------------------------------|---------|------------------------------------------------|
| `to`             | `string \| object`            | —       | Путь или объект, к которому будет вести ссылка |
| `icon`           | `React.ReactNode`             | —       | Иконка, отображаемая слева от текста ссылки    |
| `children`       | `React.ReactNode`             | —       | Текст или компоненты, отображаемые в ссылке    |
| **Прочие props** | Наследуются от `NavLinkProps` | —       | Все стандартные атрибуты компонента `NavLink`  |

---

## Активное состояние

Компонент использует метод `className` из `NavLink`, чтобы автоматически применять класс `asideLinkActive`, если ссылка
активна.

Пример применения классов:

- `styles.asideLink` — основной стиль для ссылки
- `styles.asideLinkActive` — стиль для активной ссылки

---

## Примеры

### Базовый AsideLink

```tsx
import AsideLink from '@/shared/ui/AsideLink';

<AsideLink to="/home">
  Главная
</AsideLink>
```

### AsideLink с иконкой

```tsx
import { Home } from 'lucide-react';
import AsideLink from '@/shared/ui/AsideLink';

<AsideLink to="/home" icon={<Home />}>
  Главная
</AsideLink>
```

---

## Особенности

- **Активная ссылка**: автоматически получает класс `asideLinkActive`, если ссылка активна.
- **Иконки**: можно передавать любой компонент или элемент как иконку в `icon`.
- **Поддержка всех пропсов** `NavLink`: компонент наследует все свойства от `NavLink`.
- **Динамическое содержимое**: поддержка передачи функции как children, что позволяет динамически изменять содержимое
  ссылки на основе пропсов.
