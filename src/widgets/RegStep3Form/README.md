# RegStep3Form

Форма третьего шага регистрации для добавления навыка.

Позволяет пользователю:

- указать название навыка
- выбрать категорию и подкатегорию
- добавить описание
- загрузить изображения навыка
- пройти валидацию перед отправкой

---

## Props

| Prop        | Type                                     | Default | Description                    |
|-------------|------------------------------------------|---------|--------------------------------|
| `className` | `string`                                 | —       | Дополнительный CSS класс формы |
| `onSubmit`  | `(data: SkillFormDataToApprove) => void` | —       | Callback отправки формы        |

---

## Структура формы

Форма состоит из следующих полей:

| Поле            | Компонент             | Description          |
|-----------------|-----------------------|----------------------|
| Название навыка | `Input`               | Текстовое поле       |
| Категория       | `Select<number>`      | Выпадающий список    |
| Подкатегория    | `Select<number>`      | Зависит от категории |
| Описание        | `Textarea`            | Многострочное поле   |
| Изображения     | `SkillPicturesPicker` | Загрузка файлов      |

Все поля обёрнуты в `FormField` для:

- отображения label
- отображения ошибок
