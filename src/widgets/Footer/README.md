# Footer

Компонент подвала сайта.

## Структура

- **Логотип** — используется компонент `Logo` из `shared/ui/Logo` (кружок с SVG-звездой и текст "SkillSwap")
- Три колонки навигации:
  - Первая колонка с маркерами (О проекте, Все навыки)
  - Вторая колонка (Контакты, Блог)
  - Третья колонка (Политика конфиденциальности, Пользовательское соглашение)
- Копирайт в левом нижнем углу

## Особенности

- Маркеры отображаются **только в первой колонке**
- Все цвета берутся из глобальных CSS-переменных
- Логотип использует шрифт Jost SemiBold, остальной текст — Roboto
- Позиционирование элементов — абсолютное, в соответствии с макетом

## Зависимости

- `shared/ui/Logo` — компонент логотипа (принимает опциональный пропс `href`)

## Пропсы

Компонент Footer не принимает пропсы (статический).

**Обратите внимание:** используемый внутри компонент `Logo` принимает опциональный пропс `href`:
- Если `href` передан — логотип становится ссылкой
- По умолчанию (без пропса) — просто `<div>`

## Пример использования

```tsx
import { Footer } from 'widgets/Footer';

function App() {
  return (
    <div>
      <Footer />
    </div>
  );
}
