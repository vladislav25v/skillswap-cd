# FilterSidebar Widget

Виджет боковой панели фильтрации для платформы SkillSwap. Предоставляет интерфейс для фильтрации пользователей по различным критериям.

## Архитектура

Виджет интегрирован с Redux для управления состоянием фильтров. Все изменения фильтров сохраняются в глобальном store и могут быть использованы в любом компоненте приложения.


## Зависимости

Виджет использует следующие модули:

| Модуль | Назначение |
|--------|------------|
| `features/filters` | Redux слайс для управления состоянием фильтров |
| `features/users-filter` | Бизнес-логика фильтрации пользователей |
| `api` | API функции для загрузки данных фильтров |

## Состояние фильтров

Состояние фильтров хранится в Redux и имеет следующую структуру:

| Поле | Тип | Описание |
|------|-----|----------|
| `mainFilter` | `string` | Основной фильтр: `'all'`, `'want-to-learn'`, `'can-teach'` |
| `skills` | `string[]` | Массив ID выбранных подкатегорий навыков |
| `authorGender` | `string` | Пол автора: `''`, `'male'`, `'female'` |
| `cities` | `number[]` | Массив ID выбранных городов |

## Props

| Prop | Тип | Описание |
|------|-----|----------|
| `className` | `string` | Дополнительные CSS классы |
| `onError` | `(error: Error) => void` | Callback при ошибке загрузки данных |


## API данные

Виджет загружает данные через API-слой:

| Endpoint | Данные |
|----------|--------|
| `/categories` | Список категорий навыков |
| `/subcategories` | Список подкатегорий навыков |
| `/cities` | Список городов |
