# Header

Компонент верхней части страницы. Содержит логотип, навигацию, поиск, кнопку‑иконку и кнопки входа/регистрации.

## Состав
- `Logo`
- `Nav`
- `SearchInput` (placeholder: "Искать навык")
- Кнопка‑иконка с луной (Темная тема)
- Кнопки `Войти` и `Зарегистрироваться`

## Особенности верстки
- Высота `104px`, паддинги: `36px` по кругу, снизу `20px`
- Фон `var(--color-page-bg)`
- Горизонтальный `gap: 32px` между основными элементами
- Поиск растягивается по свободной ширине (`flex: 1`, `min-width: 320px`, `height: 48px`)
- Кнопки справа сгруппированы с `gap: 8px`

import { Header } from '@/widgets/Header';
