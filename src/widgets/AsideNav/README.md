# AsideNav

Компонент навигации для сайдбара, использующий компонент `AsideLink` для отображения списка ссылок с иконками и
текстами. Каждый пункт меню отображает навигационную ссылку с соответствующей иконкой, которая активируется, когда
пользователь переходит по указанному пути.

---

## Props

| Prop        | Type     | Default | Description                             |
|-------------|----------|---------|-----------------------------------------|
| `className` | `string` | —       | Дополнительный CSS класс для контейнера |

---

## Структура

Компонент генерирует список навигации (`<ul>`), в котором каждый пункт списка (`<li>`) содержит компонент `AsideLink`.

```html
<ul class="nav">
  <li>
    <AsideLink to="empty">
      Заявки
    </AsideLink>
  </li>
  <!-- ... -->
</ul>
```

Каждый `AsideLink` включает:

- Иконку (например, `Mail`, `Heart`, `MessageSquareText`, и т. д.)
- Текст, который отображается рядом с иконкой
