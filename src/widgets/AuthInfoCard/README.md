# AuthInfoCard

Компонент информационной карточки, используемый на страницах авторизации (логин, регистрация и т.д.).

Отображает:

- изображение (опционально)
- заголовок
- текстовое описание

Подходит для отображения приветственного или поясняющего контента рядом с формой.

---

## Props

| Prop         | Type     | Default | Description                         |
|--------------|----------|---------|-------------------------------------|
| `className`  | `string` | —       | Дополнительный CSS класс контейнера |
| `picture`    | `string` | —       | URL изображения                     |
| `pictureAlt` | `string` | —       | Alt-текст изображения               |
| `title`      | `string` | —       | Заголовок карточки                  |
| `text`       | `string` | —       | Описание (текст под заголовком)     |

---

## Примеры

```tsx
import AuthInfoCard from '@/widgets/AuthInfoCard';
import bulbIcon from '@/assets/light-bulb.svg';

<AuthInfoCard
  picture={bulbIcon}
  pictureAlt={'Лампочка SkillSwap'}
  title={'С возвращением в SkillSwap!'}
  text={'Обменивайтесь знаниями и навыками с другими людьми'}
/>
```

---

## Особенности

- изображение отображается только если передан `picture`
- заголовок рендерится через компонент `Title` (`h2`)
- текст отображается только если передан `text`
- `className` добавляется к корневому элементу
- классы объединяются через `clsx`
