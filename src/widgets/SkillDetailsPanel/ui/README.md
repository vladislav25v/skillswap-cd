# SkillImageGallery

Локальная галерея изображений для `SkillDetailsPanel`.

Компонент показывает:

- основное активное изображение
- кнопки навигации вперед / назад
- колонку миниатюр
- оверлей с количеством скрытых изображений, если картинок больше трех

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `images` | `string[]` | — | Массив URL изображений |
| `imageAlt` | `string` | `''` | Alt для основного активного изображения |

## Поведение

- Если массив `images` пустой, компонент ничего не рендерит
- Если изображение одно, миниатюры и навигационные стрелки не показываются
- Одновременно отображаются максимум 3 миниатюры
- Если изображений больше 3, на последней видимой миниатюре появляется `+N`
- Активное изображение переключается по стрелкам и по клику на миниатюру

## Ограничения

- `imageAlt` применяется только к основному изображению
- Миниатюры остаются декоративными, так как кнопки вокруг них уже имеют `aria-label`
- Компонент хранит локальное состояние активного изображения через `activeIndex`

## Пример использования

```tsx
import SkillImageGallery from '@/widgets/SkillDetailsPanel/ui/SkillImageGallery';

<SkillImageGallery
  images={[
    '/img/photo-1.jpg',
    '/img/photo-2.jpg',
    '/img/photo-3.jpg',
    '/img/photo-4.jpg',
  ]}
  imageAlt="Пример навыка"
/>
```

## Стилизация

- основной layout построен на `grid`
- на узком контейнере размеры галереи уменьшаются через `@container`
- стрелки навигации позиционируются поверх основного изображения
- активная миниатюра подсвечивается рамкой и тенью
